# Portafolio · Keylor Palacios Gómez

Next.js 15 (App Router) + TypeScript. Sin librerías de UI: solo CSS.

## Uso
```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

## Editar contenido
Todo el texto vive en `lib/data.ts`. El CV descargable está en `public/CV_Keylor_Palacios.pdf`
(reemplázalo con el mismo nombre cuando lo actualices).

## Desplegar
Sube el proyecto a GitHub e impórtalo en Vercel; no requiere configuración adicional.
